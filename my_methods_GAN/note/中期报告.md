## SC-GridRestore 方法基本原理

### 1. 方法提出背景与核心思路

在真实通信链路中，语音通常需要经过 Opus、AMR-WB、G.711 等编解码器压缩后再进行传输或存储。编码过程会引入频谱空洞、相位扰动、带宽受限与量化噪声等复合失真，从而使同一说话人的 clean 语音与 coded 语音在后端说话人嵌入空间中产生明显偏移。若直接针对每一种 codec 和每一个码率重新训练后端模型，不仅训练成本高，而且还会带来模型版本管理复杂、迁移困难和维护压力大等工程问题。基于这一现实约束，SC-GridRestore 采用“**前端修复失真、后端保持不变**”的总体思路：先利用前端恢复模块将 coded 语音映射为更接近 clean 分布的 restored 语音，再将其送入固定后端完成嵌入提取与相似度打分。该方法既保留了既有后端模型的稳定性，又通过单一前端模块适配多种编码条件，因此具有较好的通用性与部署可行性。

进一步地，从任务属性来看，codec 失真并非随机噪声，而是与编码器结构、码率配置和带宽限制密切相关的“结构化退化”。这意味着恢复模型不仅需要补偿谱幅值偏差，还需要修正跨帧与跨频带的时频关系。因此，SC-GridRestore 选择在时频域建模，并在训练中引入说话人一致性约束，使恢复结果同时满足两类要求：一是在声学层面尽可能接近 clean 语音，二是在身份层面尽可能保留说话人判别信息。与传统单纯面向语音可懂度或感知质量的增强方法不同，SC-GridRestore 更强调“**声学可恢复性**”与“**身份可辨性**”的联合优化，从而避免传统降噪范式在说话人任务中常见的过平滑问题。

从系统实现角度看，SC-GridRestore 具有“**训练复杂、推理轻量**”的特点：复杂性主要集中在训练阶段的多目标联合优化与三阶段课程式调度，而部署阶段仅需一次前向恢复即可直接插入既有识别链路。因此，该方法非常适合真实业务中的增量改造场景，即在不改动原有后端识别模型和标定流程的前提下，通过插入前端模块快速获得鲁棒性增益。

### 2. 数学建模与问题定义

设原始 clean 语音波形为 (x\in\mathbb{R}^{T})，经过编码器类型 (m) 和码率 (b) 所确定的压缩算子 (\mathcal{C}_{m,b}(\cdot)) 后，得到 coded 语音 (x_c)。编码过程可抽象表示为：

$$
\begin{equation}
x_c = \mathcal{C}_{m,b}(x).
\tag{1}
\end{equation}
$$

SC-GridRestore 的目标是在不改动后端模型的前提下，学习从 coded 语音到 restored 语音的恢复映射。若将生成器记为 (G_{\theta}(\cdot))，其中 (\theta) 表示生成器参数，则其基本映射可表示为：

$$
\begin{equation}
\hat{x} = G_{\theta}(x_c).
\tag{2}
\end{equation}
$$

其中，(\hat{x}) 表示恢复后的语音。训练目标并不是简单地让 (\hat{x}) 在波形空间逼近 (x)，而是同时要求 (\hat{x}) 在**重建指标**和**说话人一致性指标**上都逼近 (x)。换言之，SC-GridRestore 的优化目标不仅要减少压缩语音与 clean 语音之间的声学差异，还要减小由编码失真引起的说话人嵌入偏移。

### 3. 生成器的时频残差恢复机制

SC-GridRestore 采用时频域残差恢复思路。首先，对 coded 波形执行短时傅里叶变换（STFT），得到其复数频谱表示。若记 STFT 算子为 (\mathcal{S}(\cdot))，则 coded 语音的时频表示写为：

```latex
\begin{equation}
X_c = \mathcal{S}(x_c).
\tag{3}
\end{equation}
```

随后，网络在复谱域中对失真残差进行估计。若将残差估计网络记为 (\Phi_{\theta}(\cdot))，则残差谱可表示为：

```latex
\begin{equation}
\Delta X = \Phi_{\theta}\!\bigl(\operatorname{Re}(X_c), \operatorname{Im}(X_c)\bigr).
\tag{4}
\end{equation}
```

其中，(\operatorname{Re}(\cdot)) 和 (\operatorname{Im}(\cdot)) 分别表示复谱的实部和虚部。网络并不直接从零生成目标频谱，而是学习“coded 频谱与 clean 频谱之间的差值”，即失真补偿量。最后，通过逆短时傅里叶变换（iSTFT）将残差谱映射回时域，并采用残差形式得到最终恢复语音：

```latex
\begin{equation}
\hat{x} = x_c + \mathcal{S}^{-1}(\Delta X).
\tag{5}
\end{equation}
```

这一建模方式的优势在于：其一，coded 语音已经包含了大量有效的语音结构信息，直接在其基础上进行残差补偿比“从零重建整段语音”更容易优化；其二，模型参数可以更集中地用于学习 codec 伪影、频带缺失和跨帧失真关系的修正，从而提高训练效率与恢复质量。文档中明确给出了这一“复谱残差估计 + iSTFT 回时域 + 波形残差相加”的主线。

进一步地，在网络结构层面，SC-GridRestore 的生成器采用 **STFT → CWS → TF-GridNet → 逆 CWS → iSTFT** 的结构。具体而言，首先将 coded 波形映射到复谱域，并将实部和虚部堆叠形成两通道输入；然后通过 CWS（子带重排）操作，将原始频带重组为更紧凑的子带表示，使模型能够在有限参数量下更有效地捕捉 codec 伪影的局部模式；接着，堆叠多层 TF-GridNet block，同步沿时间维与频率维传播信息，联合建模局部频带纹理与长程上下文关系；最后再通过逆 CWS 和 iSTFT 恢复到时域波形。文档还给出了生成器默认的结构超参数，例如 STFT 采用 (n_fft=512)、(hop=128)、(win=512)，CWS 子带数 (K=3)，GridNet block 数 (B=5\sim 6)，嵌入通道默认约为 64 左右。

若将实虚部拼接后的时频输入记为 (\mathbf{R}_0)，CWS 重排后的表示记为 (\mathbf{Z}_0)，则生成器内部的主干计算可进一步写为：

```latex
\begin{equation}
\mathbf{R}_0 = \operatorname{RI}(\mathcal{S}(x_c)) \in \mathbb{R}^{2 \times T_f \times F},
\tag{6}
\end{equation}
```

```latex
\begin{equation}
\mathbf{Z}_0 = \operatorname{CWS}(\mathbf{R}_0) \in \mathbb{R}^{(2K)\times T_f \times (F/K)},
\tag{7}
\end{equation}
```

```latex
\begin{equation}
\mathbf{H}_0 = \operatorname{Conv}_{1\times 1}(\mathbf{Z}_0), \qquad
\mathbf{H}_{b+1} = \mathcal{G}_b(\mathbf{H}_b), \; b=0,\dots,B-1,
\tag{8}
\end{equation}
```

```latex
\begin{equation}
\Delta \mathbf{R} = \operatorname{InvCWS}\!\bigl(\operatorname{Conv}_{1\times 1}(\mathbf{H}_B)\bigr),
\tag{9}
\end{equation}
```

```latex
\begin{equation}
\hat{x} = x_c + \mathcal{S}^{-1}(\Delta \mathbf{R}).
\tag{10}
\end{equation}
```

其中，(\mathcal{G}_b(\cdot)) 表示第 (b) 个 TF-GridNet block。该类 block 在当前实现中包含频域卷积分支、时间方向双向 GRU 与多头注意力、频率方向双向 GRU 等模块，通过在时间轴与频率轴上交替传播信息，提升对结构化编码失真的建模能力。

### 4. 多目标联合损失函数

SC-GridRestore 并非单纯依靠一个重建目标进行优化，而是采用多目标联合训练框架。总体损失函数可写为：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{total}} =
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}} +
\lambda_{\mathrm{spk}}\mathcal{L}_{\mathrm{spk}} +
\lambda_{\mathrm{gan}}\mathcal{L}_{\mathrm{adv}} +
\lambda_{\mathrm{fm}}\mathcal{L}_{\mathrm{fm}} +
\lambda_{\mathrm{wavlm}}\mathcal{L}_{\mathrm{wavlm}}.
\tag{11}
\end{equation}
```

其中，(\mathcal{L}*{\mathrm{rec}}) 为重建损失，(\mathcal{L}*{\mathrm{spk}}) 为说话人一致性损失，(\mathcal{L}*{\mathrm{adv}}) 为生成器侧对抗损失，(\mathcal{L}*{\mathrm{fm}}) 为判别器特征匹配损失，(\mathcal{L}*{\mathrm{wavlm}}) 为可选的高层表征蒸馏损失；(\lambda*{*}) 表示各损失项的权重系数。文档明确指出，不同损失项承担的作用不同：(\mathcal{L}*{\mathrm{rec}}) 负责“听起来像 clean”，(\mathcal{L}*{\mathrm{spk}}) 负责“嵌入上像同一个人”，(\mathcal{L}*{\mathrm{adv}}) 与 (\mathcal{L}*{\mathrm{fm}}) 负责“分布上像真实语音”，而 (\mathcal{L}_{\mathrm{wavlm}}) 则提供更高层的语义与时序一致性约束。

#### 4.1 重建损失

重建损失由 SI-SDR、MRSTFT 和复谱损失三部分构成，即：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{rec}} =
\alpha \mathcal{L}_{\mathrm{SI\text{-}SDR}} +
\beta \mathcal{L}_{\mathrm{MRSTFT}} +
\gamma \mathcal{L}_{\mathrm{CPLX}}.
\tag{12}
\end{equation}
```

其中，(\mathcal{L}*{\mathrm{SI\text{-}SDR}}) 用于度量恢复波形与目标波形之间的时域相似性；(\mathcal{L}*{\mathrm{MRSTFT}}) 用于约束多分辨率频谱结构的一致性；(\mathcal{L}_{\mathrm{CPLX}}) 则进一步在复数频谱域内约束实部与虚部的差异。文档中已明确将三者作为当前实现中的基础重建项。

其中，SI-SDR 项可写为：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{SI\text{-}SDR}} =
-10\log_{10}
\frac{
\left\|
\frac{\langle \hat{x},x\rangle}{\|x\|^2}x
\right\|^2
}{
\left\|
\hat{x}-
\frac{\langle \hat{x},x\rangle}{\|x\|^2}x
\right\|^2
}.
\tag{13}
\end{equation}
```

#### 4.2 说话人一致性损失

为了确保恢复语音在后端嵌入空间中仍能保持与 clean 语音一致的身份属性，SC-GridRestore 在重建基础上引入了说话人一致性损失。若固定后端说话人模型记为 (f_{\mathrm{spk}}(\cdot))，则最基本的嵌入余弦一致性项可表示为：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{spk\text{-}cos}}
=
1-\cos\!\left(
f_{\mathrm{spk}}(\hat{x}),
f_{\mathrm{spk}}(x)
\right).
\tag{14}
\end{equation}
```

在此基础上，文档进一步给出了更完整的说话人一致性项表达形式：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{spk}} =
\underbrace{\left(1-\cos\left(f_{\mathrm{spk}}(\hat{x}),f_{\mathrm{spk}}(x)\right)\right)}_{\mathcal{L}_{\mathrm{spk\text{-}cos}}}
+\eta \mathcal{L}_{\mathrm{spk\text{-}feat}}
+\mu \mathcal{L}_{\mathrm{AM}}.
\tag{15}
\end{equation}
```

其中，(\mathcal{L}*{\mathrm{spk\text{-}feat}}) 表示后端深层特征的一致性约束，(\mathcal{L}*{\mathrm{AM}}) 表示可选的 AM-Softmax 分类项。该设计使恢复结果不再仅追求波形近似，而是朝着“更利于后端说话人判别”的方向优化。

#### 4.3 对抗损失与特征匹配损失

在 Phase 3 中，SC-GridRestore 进一步引入判别器以提升恢复语音的真实性和高频细节。文档中采用 LSGAN 形式给出了判别器和生成器侧的对抗目标。判别器损失可写为：

```latex
\begin{equation}
\mathcal{L}_{D} =
\mathbb{E}_{x}\left[(D_{\phi}(x)-1)^2\right]
+
\mathbb{E}_{x_c}\left[D_{\phi}(\hat{x})^2\right],
\tag{16}
\end{equation}
```

对应的生成器侧对抗损失为：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{adv}} =
\mathbb{E}_{x_c}\left[(D_{\phi}(\hat{x})-1)^2\right].
\tag{17}
\end{equation}
```

此外，为了进一步稳定训练并约束判别器中间层表征，文档还引入了特征匹配损失：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{fm}} =
\sum_{i}\sum_{j}\frac{1}{N_{ij}}
\left\|
D_i^{(j)}(x)-D_i^{(j)}(\hat{x})
\right\|_1.
\tag{18}
\end{equation}
```

其中，(D_i^{(j)}(\cdot)) 表示第 (i) 个判别器第 (j) 层的特征输出，(N_{ij}) 表示该层特征的归一化因子。对抗项与特征匹配项共同作用，可以在不过度牺牲说话人一致性的前提下改善恢复语音的分布真实性与听感自然度。文档还说明当前判别器主要由多分辨率时频判别器（MRD）构成，并可选多频带波形判别器（MBD），两者分别从谱形真实性与波形子带一致性两个角度形成互补约束。

#### 4.4 高层表征蒸馏损失

若启用高层表征蒸馏，则进一步加入 WavLM 特征约束：

```latex
\begin{equation}
\mathcal{L}_{\mathrm{wavlm}} =
\left\|
f_{\mathrm{wavlm}}(\hat{x})-f_{\mathrm{wavlm}}(x)
\right\|_1.
\tag{19}
\end{equation}
```

该项用于从更高层的语义和时序表示角度约束恢复语音与目标语音的一致性，不过文档同时强调，这一项并非固定启用，而是作为 Phase 3 中的可选增强项。

### 5. 三阶段课程式训练策略

为了兼顾收敛稳定性与目标完整性，SC-GridRestore 采用课程式三阶段优化策略。文档明确指出，其基本思想可以概括为“**先保证可重建，再强调可识别，最后提升分布真实性与细节自然度**”。三阶段目标写为：

```latex
\begin{equation}
\min_{\theta}
\begin{cases}
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}, & \text{Phase 1}, \\[4pt]
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}+\lambda_{\mathrm{spk}}\mathcal{L}_{\mathrm{spk}}, & \text{Phase 2}, \\[4pt]
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}
+\lambda_{\mathrm{spk}}\mathcal{L}_{\mathrm{spk}}
+\lambda_{\mathrm{gan}}\mathcal{L}_{\mathrm{adv}}
+\lambda_{\mathrm{fm}}\mathcal{L}_{\mathrm{fm}}
+\lambda_{\mathrm{wavlm}}\mathcal{L}_{\mathrm{wavlm}}, & \text{Phase 3}.
\end{cases}
\tag{20}
\end{equation}
```

```latex
\begin{equation}
\min_{\theta}
\begin{cases}
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}, & \text{Phase 1}, \\[4pt]
\lambda_{\mathrm{rec}}\mathcal{L}_{\mathrm{rec}}+\lambda_{\mathrm{spk}}\mathcal{L}_{\mathrm{spk}}, & \text{Phase 2}
\end{cases}
\tag{20}
\end{equation}
```
其中，Phase 1 仅优化重建目标，用于建立稳定的声学映射基础，降低后续多目标优化时的搜索难度；Phase 2 在此基础上引入说话人一致性约束，使恢复结果不再仅追求波形近似，而是朝着“更利于说话人判别”的方向优化；Phase 3 再通过判别器反馈修复细粒度伪影，改善主观自然度与高频细节一致性。文档强调，这种递进式训练能够显著降低“直接全损失训练”中常见的震荡、梯度冲突和局部最优问题。

从调参策略上看，SC-GridRestore 也遵循“先稳后强”的原则：先固定重建主权重以保证基本收敛，再逐步提升说话人项和对抗项的比重；如果验证集上重建改善明显但 SV 指标停滞，则提高 (\lambda_{\mathrm{spk}})；如果语音自然度不足但 SV 已有提升，则适度提高 (\lambda_{\mathrm{gan}}) 和 (\lambda_{\mathrm{fm}})。这一策略与三阶段训练的组织方式是一致的。

### 6. 训练与推理执行流程

SC-GridRestore 的训练与推理流程可概括为六步。第一，构建 ((x,x_c)) 配对数据，并尽可能覆盖多种 codec 与多种码率条件；第二，对样本执行可选的 codec 时移补偿、长度对齐与分段裁剪；第三，前向计算恢复语音 (\hat{x}=G_{\theta}(x_c))；第四，按照当前训练阶段计算对应损失并更新参数，在 Phase 3 中同步更新判别器；第五，在验证集上联合监控重建性能和说话人一致性，选择最优模型；第六，在推理阶段仅保留生成器，将 restored 语音送入固定后端完成嵌入提取与相似度打分。文档对这一流程已有明确列举，并特别强调推理阶段“仅保留生成器”的轻量部署特性。

此外，在工程落地时还需要注意两个问题。其一，训练集应尽量覆盖目标场景中的 codec 类型与码率分布，以避免前端在域外条件下泛化不足；其二，验证与评测建议采用 clean / coded / restored 三路并行对比，以明确区分“相对 coded 的增益”和“距 clean 上限的差距”。这种评测方式既能证明方法有效性，也有助于定位当前系统的剩余瓶颈。
